# dvre_authentication

[![Github Actions Status](/workflows/Build/badge.svg)](/actions/workflows/build.yml)

A JupyterLab extenstion.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install dvre_authentication
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall dvre_authentication
```
